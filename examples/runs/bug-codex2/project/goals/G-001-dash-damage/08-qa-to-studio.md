# 08: qa → studio — 基本資料は補完済み、補足観察資料の開始条件は未充足

## Task

Studio は実行環境側に補足観察資料の提供可否・取得先・入手方法を確認し、回答を記録する。資料が提供され、再開条件を満たすまで QA に同じ資料で再試行を依頼しない。

## Context

Owner の依頼は「ダッシュ中なのにダメージを受けることがある。再現できるので直してほしい」。

07 は補足観察資料の受領と Studio による Load・開始条件の確認を再現確認の前提としている。今回の packet には QA Role、reproduce-defect Skill、Project の必要節、戦闘仕様、模擬ビルド、06 の本文が含まれる。一方、補足観察資料と実行環境側の回答は含まれていない。

## Findings

`studio/skills/reproduce-defect.md` に基づき、入力の充足状況のみ確認した。07 が指摘した基本資料の本文不足は今回解消しているが、補足観察資料の不足は解消していない。開始条件が未充足のため、追加再現確認は開始していない。

- 期待値の出典：`design/combat.md` はダッシュ全期間 0.25 秒の無敵を定める。
- 既存の観察記述：`sim/build-0.3.md` は、被弾直後にダッシュすると時折ダッシュ途中でダメージを受けると記載している。新規観察ではない。
- 配置、操作、イベント時刻、ハート変化、条件別試行数・発生数は未提供。再現手順と頻度は確定できない。
- キーボード／ゲームパッド × 30／60 FPS の全4組み合わせは未検証。
- 被弾後 0.8 秒までの無敵にも違反するかは未確認。「被弾直後」から具体的な時刻や入力予約を推測しない。
- 重大度は06の「体験を損なう不具合」という既存評価を引き継ぐ。進行不能や死亡の証拠はない。

実機実行、追加試行、実装変更は行っていない。再現確定、修正済み、検証合格とは判定しない。技術的原因は未確定である。

資料の提供可否は「未確認」であり、「提供不能」とは判断していない。

### 引き継ぐ受け入れ条件

以下は変更せず、すべて未検証とする。

1. 被弾後、入力可能になってから開始したダッシュ全期間で、Grub の接触攻撃・Spitter の弾によってハートが減らない。
2. 直前に被弾していない場合も、同じ攻撃に対してダッシュ全期間でハートが減らない。
3. ダッシュ開始直後・途中・終了直前で上記を満たす。終了後も被弾後の無敵が残る間はダメージを受けず、両方の無敵終了後の有効な命中では通常どおり 1 ハート減る。
4. 移動距離 4 タイル、時間 0.25 秒、クールダウン 0.6 秒、ダッシュ中の攻撃入力が終了時に発動する挙動を維持する。
5. Desktop のキーボード／ゲームパッドと 30／60 FPS の全組み合わせで確認する。

## Decisions already made

新しい Decision はない。既存仕様への修正として進め、追加 Design は省略し、Build はまだ開始しないという方針を維持する。

## Constraints

- Dry-run の資料読解と実機実行を区別する。
- QA は実装を変更せず、実装者の自己評価や reasoning を検証根拠にしない。
- 再現条件、観察結果、頻度、原因を創作しない。
- 入力不能中のダッシュ予約や完全同時の境界処理を新たに規定しない。
- 入力追加は `project.md#constraints` に従う。戦闘の方向性変更と無関係な調整は対象外。
- 補足観察資料なしで同じ packet による QA 再試行を行わない。

## Open questions

- 実行環境側は補足観察資料を提供可能か。取得先と入手方法は何か。
- 部屋、敵の種類・数、初回と再被弾の命中源、位置関係、ダッシュ方向は何か。
- 初回被弾、入力不能終了、ダッシュ入力・開始、再被弾、ダッシュ終了の時刻とハート変化はどうなっているか。
- 被弾からダッシュまでの間隔、攻撃種別、入力方式、FPS 別の試行数・発生数と未観察範囲は何か。

## Expected output

Studio は実行環境側の回答として、資料の提供可否・取得先・入手方法を記録する。

提供可能なら実在する資料の所在と本文を Load に追加し、開始条件を確認して QA に渡す。一部のみ提供された場合は不足を明記し、提供資料で確認できる範囲の判断を QA に委ねる。

提供不能なら、その事実と理由を blocker として記録し、再ルーティングの根拠とする。回答がない間は未確認を維持し、同じ資料だけで再現確定や Build 開始へ進めない。
