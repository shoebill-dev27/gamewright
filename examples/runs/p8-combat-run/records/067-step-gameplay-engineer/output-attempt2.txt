## Context

Goal G-001. Handoff 69 asked for wording-only changes: the wind-up and hit messages name the variant, and the manual gets the late-swipe and in-flight wording. Build label: 0.6.1 plus D-011. There is no sha in this environment. The banner still prints `Lantern Depths 0.6`, as the existing banner test requires. Suggested label for the playtest brief: 0.6.2 (D-011), per D-009 item 5.

## Findings

What changed and where:

- `repo/game.py`: `_hurt` takes an optional `enemy` name. A grub lunge hit passes the variant, so the `hurt` event carries `enemy` (grub, runner or brute). `source` stays `"grub"` or `"shot"`, so bots and all existing logic are untouched. Shot hits carry no `enemy`.
- `repo/play.py` (player view only):
  - The wind-up message is `a <enemy> rears back` (grub, runner or brute).
  - The hit message is `YOU ARE HIT by a <enemy|source> — hearts n/3`. Shots still print `by a shot`.
  - The trace view hides the new `enemy` field in `hurt` events, so trace output stays byte-identical to 0.6.1.
  - The `cue:` line, `~` line, timings, and the swipe, kill, shrug and spitter messages are unchanged.
- `repo/manual.md`:
  - Warnings bullet names the three wind-up messages.
  - Late-swipe text is the exact text from step 68 §2.
  - The stale "no more than 3 are in the air at once" is replaced by the exact step 68 §1 sentence.
  - The hit-message line lists all four hit messages.
- `repo/tests/test_game.py`: new `VariantMessageTest` (see below). No existing test keyed on the old strings other than `a grub rears back` for a grub, which is still correct.
- No bot needed changing. Bots key on event `source`, not on message text.

How to exercise (practice room, 30 and 60 FPS, one case per variant):

- `room empty`, `spawn <grub|runner|brute> 10 4`, `player 8 4`, `end 1.0`: one `a <variant> rears back` line at the wind-up moment.
- Same with the spawn at 8.5 4: the hit line reads `YOU ARE HIT by a <variant> — hearts 2/3` at the frame of contact.
- A script with `when text "rears back" then dash away` reacts to all three.
- A script keyed on `text "a grub rears back"` reacts only to the standard grub.
- `--view trace` hurt lines show only `{'source': 'grub', 'hearts': n}`.

New tests (`VariantMessageTest`), all at 30 and 60 FPS:

- each wind-up prints its message once and no other variant's message;
- the wind-up message sits at the windup event time;
- each hit prints the matching message on the contact frame with the unchanged hearts text;
- the shot, aim, spit and shrug strings are unchanged;
- the `rears back` rule reacts to all three;
- the `a grub rears back` rule matches only the grub;
- the trace shows no `enemy` field.

Acceptance criteria addressed: V-a, V-b, V-c, V-d by those tests and by construction (only the string formatting changed; the simulation is untouched). V-e: the simulation, bots and rooms are untouched. The manual wording covers the step 59 acceptance list and the step 68 §1 replacement.

class VariantMessageTest(unittest.TestCase):
    """D-011: wind-up and hit messages name the variant; everything else is unchanged."""

    KINDS = ("grub", "runner", "brute")

    def session(self, script, view="player"):
        import contextlib
        import io

        import play

        setup, inputs, rules = play.read_script(script)
        out = io.StringIO()
        with contextlib.redirect_stdout(out):
            play.play(setup, inputs, view, rules)
        return out.getvalue()

    def script(self, kind, fps, x, extra="", end=2.5):
        return f"room empty\nfps {fps}\nspawn {kind} {x} 4\nplayer 8 4\n{extra}end {end}\n"

    def test_each_wind_up_prints_its_own_message_once(self):
        for fps in (30, 60):
            for kind in self.KINDS:
                out = self.session(self.script(kind, fps, 10, end=1.0))
                self.assertEqual(out.count(f"a {kind} rears back"), 1, (fps, kind))
                for other in self.KINDS:
                    if other != kind:
                        self.assertNotIn(f"a {other} rears back", out, (fps, kind))

    def test_wind_up_message_is_at_the_wind_up_moment(self):
        for fps in (30, 60):
            for kind in self.KINDS:
                game = Game(fps=fps, room="empty")
                game.spawn(kind, 10, 4)
                self.assertTrue(step_until(game, has_event("windup")))
                when = times(game, "windup")[0]
                out = self.session(self.script(kind, fps, 10))
                self.assertIn(f"{when:7.3f}  a {kind} rears back", out, (fps, kind))

    def test_each_hit_prints_the_matching_message_on_the_frame_of_contact(self):
        for fps in (30, 60):
            for kind in self.KINDS:
                game = Game(fps=fps, room="empty")
                game.spawn(kind, 8.5, 4)
                self.assertTrue(step_until(game, has_event("hurt"), 3.0))
                when = times(game, "hurt")[0]
                out = self.session(self.script(kind, fps, 8.5))
                self.assertIn(
                    f"{when:7.3f}  YOU ARE HIT by a {kind} — hearts 2/3", out, (fps, kind)
                )

    def test_shot_hit_and_other_messages_are_unchanged(self):
        import play

        d = play.Player.describe
        self.assertEqual(d("hurt", {"source": "shot", "hearts": 2}), "YOU ARE HIT by a shot — hearts 2/3")
        self.assertEqual(d("aim", {}), "a spitter takes aim")
        self.assertEqual(d("spit", {}), "a spitter spits")
        self.assertEqual(d("shrug", {"enemy": "brute"}), "the brute shrugs off the swipe")

    def test_rears_back_rule_reacts_to_all_variants(self):
        for fps in (30, 60):
            for kind in self.KINDS:
                out = self.session(
                    self.script(kind, fps, 10, 'when text "rears back" then dash away\n')
                )
                self.assertIn("you dash", out, (fps, kind))

    def test_old_keyed_rules_match_only_the_standard_grub(self):
        for kind, expect in (("grub", True), ("runner", False), ("brute", False)):
            out = self.session(
                self.script(kind, 60, 10, 'when text "a grub rears back" then dash away\n')
            )
            self.assertEqual("you dash" in out, expect, kind)

    def test_trace_view_hides_the_variant_field(self):
        out = self.session(self.script("brute", 60, 8.5, end=1.5), view="trace")
        hurt = [l for l in out.splitlines() if "hurt {" in l]
        self.assertTrue(hurt)
        for line in hurt:
            self.assertIn("hurt {'source': 'grub', 'hearts': 2}", line)
            self.assertNotIn("'enemy'", line)


if __name__ == "__main__":
